# Blog Images Directory

This directory contains images for blog posts on KisanMarkaz. Images should be:
- Optimized for web (compressed, appropriate dimensions)
- Relevant to the content
- High quality and professional
- Named descriptively using kebab-case
- Include alt text in the blog post component

## Image Naming Convention
- Use lowercase letters
- Use hyphens to separate words
- Include relevant keywords
- Example: smart-farming-technology.jpg
